## Bugs Fixed

### Reminder Storage Bug

Found:

* `AttributeError: 'dict' object has no attribute 'append'`

Cause:

`load_reminders()` returns:

```json
{
    "reminders": []
}
```

but `add_reminder()` attempted:

```python
reminders.append(...)
```

Fixed by changing to:

```python
reminders["reminders"].append(...)
```

---

### Telegram Handler Bug

Found:

Reminder commands were being forwarded to Gemini instead of being handled by the Telegram command handlers.

Cause:

The catch-all chat handler was registered before the reminder command handlers.

Fixed by moving the reminder command handlers above the catch-all handler so Telegram processes command-specific handlers first.

Verified:

* `/reminder_add`
* `/reminders`
* `/reminder_done`

now execute correctly without invoking Gemini.
