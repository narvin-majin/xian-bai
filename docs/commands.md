# Xian Bai Commands

## General

### /start
Shows the welcome message.

### /status
Displays:
- Current task
- Status
- Streak
- Focus level
- Fatigue level

### /track <task>
Starts tracking a task.

Example:
/track Learn Python

### /done
Marks the current task as completed.

---

## Projects

### /project_create <name>
Creates a project.

### /projects
Lists all projects.

### /project_switch <name>
Makes a project active.

### /project_task_add <task>
Adds a task to the active project.

### /project_tasks
Lists tasks in the active project.

### /project_task_done <number>
Marks a project task as completed.

Example:
/project_task_done 3
